# Excalicord 网页操作

入口：https://excalicord.com/

本说明基于 2026-10-01 网页实测，不假定未来按钮与布局不变。每次依据当前界面操作，不复用旧元素编号、窗口坐标或标签页 ID。

## 导入与分页

1. 找到正确的 Excalicord 标签页。检查现有内容，替换前保存仍需要的作品；不能把另一项目当作空白测试页。
2. 使用画布左上角菜单中的“打开”，选中生成的文件。应通过网页打开文件，不能把文件路径当成浏览器网址。
3. 文件选择器只使用当前环境支持的方式。若采用原生窗口，先确认正确标签页在前台，再操作该窗口；快捷键落在其他页面会产生错误行为。
4. 导入含原生 frame 的场景后，核对幻灯片栏。点击至少两个页码，确认页面定位改变；双击标题进入文字编辑，再退出而不改动。
5. 编辑视图可能同时显示邻页，这是无限画布的正常现象。不能仅凭编辑视图判定最终录制取景范围。
6. 打开录制设置，选创作者确认的比例；在界面确认选中状态。每页 1080×1440 坐标不等于视频一定以此像素导出。

## 提词器

打开文稿图标对应的提词器，先读现有内容。填入已获创作者批准的最终稿，保留段落和【切换第 N 页】提示，去掉 Markdown 标题符号等阅读噪声即可，不做语义改写。

填入后读回完整文本，与批准稿对照。确认页码齐全、正文首尾完整、文字仍可修改；回到开头并保留提词器展开状态。不要默认启动自动滚动或录制。

若环境支持保存实际网页截图，提供截图证据；公開分享截图时不能带入创作者的摄像头画面或私人内容。任务交付截图只给当前创作者。

## 录制验收

上次网页提示录制时用 ← / → 切页。应在不聚焦文字输入框的情况下试录验证；提词器文字编辑时方向键可能移动光标。短试录检查：

- 当前页取景正确，切页无遗漏。
- 画面比例正确，导出视频尺寸经实际文件确认。
- 麦克风声音清楚、人像不挡内容。

这些不能用按钮可点击、静态截图或页面加载成功来代替。

## 阻碍与完成状态

浏览器连接中断可依据工具说明重新检查连接；遇到安全拒绝不能通过其他接口绕过。现场操作失败时停止依赖步骤，保留文件并说明人工接手位置。不能安装一套新应用或修改网站源码来解决简单的导入问题。

检查网页是否保存稿件的持久性需要另行验证；没有测试前只说“已填入当前页面”，不要保证换浏览器、关闭网页后依然存在。
