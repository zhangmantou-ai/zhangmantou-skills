# Excalicord 白板创作助手

把素材制作成创作者能够继续修改、逐页讲述的白板。验收地点是 **Excalicord 网页**。交付文件的扩展名不能代替实际编辑、分页验证。

## 创作约定

- 沿用本次对话中已经明确的选择。每次只确认一组相关问题，并给出适合素材的建议；不要一次抛出问卷。
- 保留创作者的观点，不补造经历、数据、效果或工具使用记录。扩展示例与原始事实分开标明。
- 明确的“确认”“按这个做”可以作为对应阶段的批准；沉默、超时和工具输出不能代替创作者批准。
- 不安装额外模型、不部署服务、不改造 Excalicord。使用当前 AI 对话和已有浏览器能力完成工作。
- 3:4 是小红书竖版的建议选项，不是所有创作者的固定规格；已有比例要求优先。可采用 1080×1440 作为 3:4 画框坐标。

## 工作流程

### 1. 确认表达方向

先归纳素材主题、观点与缺失信息。逐步确认这些会实质影响结果的选择：

1. 想讲什么、讲给谁、希望观众记住什么。
2. 文字为主／文字配简单图形／图解为主；简洁／适度解释／详细展开。
3. 视觉风格、画面比例、预计时长，以及是否为摄像头人像预留位置。

不要把“图解为主”等同于装饰图多。用流程、对比、时间线、层级或因果关系帮助表达。能从素材和已有上下文判断的部分，提出明确建议让创作者确认。

### 2. 确认分页结构

提供短表：页码、标题、要讲的重点、表达方式。页数由内容和可读性决定，不固定六页。先取得结构确认，再制作完整白板。

涉及新视觉风格且创作者难以想象时，先做一页样张确认，再展开其余页。不要把每个字号、间距变成新的审批步骤。

### 3. 制作可编辑白板

读取 [文件制作与检查](references/scene-format.md)。用 `scripts/build_scene.py` 将通用布局 JSON 转为包含原生 frame 的 `.excalidraw` 文件；脚本仅负责可靠输出，不负责替 AI 决定结构和布局。

- 文字、形状、线条、箭头使用原生元素；分组通过 `groupIds` 表达，不创建不存在的 `group` 元素类型。
- 每页一个指定尺寸的 frame，内容正确归属对应 frame；所有页面比例一致。
- 一页放不下就分页；不要为塞内容把字无限缩小。
- 优先制作有意义的图形关系，避免每个主题都变成相同的文字卡片列表。
- 有摄像头时，根据确认的位置预留空间。未知时先问，不擅自挡住内容。
- 素材库按需使用。保留来源和许可记录；未取得图形时不宣称已调用素材库。位图不能冒充可编辑图形。
- 检查页尺寸、元素边界、文本实际换行和视觉效果。静态排版预览与网页实际截图必须分别标识。

### 4. 在 Excalicord 修改与确认

读取 [网页操作与提词器](references/excalicord-browser.md)。先保护当前画布，再通过网页自身“打开”功能导入。

验证分页数量、至少两个页码的切换、文字进入原生编辑状态，以及录制设置中的目标比例。把页面交给创作者修改与确认。若修改发生在网页，以导出后的最终白板或明确修改记录为准，不能继续用旧文件生成稿件。

### 5. 生成并确认口播稿

根据已确认的最终白板逐页写稿。口播负责解释和过渡，不逐字重复页面。用明确的【切换第 N 页】及必要动作提示对齐页码，提示不用念。

让创作者确认措辞、观点、顺序和节奏。未经过实测的时长只能标为估计。

**必须取得创作者对最终口播稿的确认，才执行第 6 步。** “帮我生成稿件”不是“已确认稿件”。创作者要求修改时，先改稿并重新确认；已经批准的最终版本无需重复询问。

### 6. 将已确认稿件直接填入提词器

- 用当前环境支持的浏览器操作工具打开 Excalicord 提词器。
- 检查是否已有稿件；若是无关内容，先询问覆盖或追加，不能静默替换。
- 填入确认的正文，只做提词器必要的格式整理，不重新改写内容。保留分页与动作提示。
- 读回并检查开头、结尾、全部分页和正文完整性；确认文本框仍可编辑，停在开头。
- 若需修正已确认稿件的语义，回到第 5 步。
- 保留页面并交付实际截图。自动滚动和录制由创作者启动，除非另有明确授权。

没有可用浏览器能力、登录未完成、权限被拒绝或页面不支持时，交付已完成的白板与口播稿，说明具体阻碍和最短人工操作。将“提词器填入”标为未完成，不能声称整个工作流已完成。

## 完成交付

提供白板源文件、逐页口播稿和简短使用说明；说明实际检查结果与待人工确认项。需要时附排版预览及网页截图。

区分：源文件生成、Excalicord 导入编辑、录制中切页、声音与人像、视频导出。没有实际录制就不能宣称录制通过；录制中切页和导出尺寸应通过短试录验收。

面向公开分享时，去掉私人路径、账号、摄像头画面、凭据及无授权第三方素材。该 Skill 不授予向 GitHub 或其他网站发布用户内容的权限。
