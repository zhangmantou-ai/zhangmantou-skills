# 张馒头观点口播视频

由张馒头的观点口播实践整理，服务于使用者的真实表达。首次使用读取 [个人设置](references/preferences.md)，把下文的“用户”理解为当前使用者。默认成片是 **本人原声＋根据口播内容匹配的视频背景＋暖白动态大字＋黄色关键词**，竖版9:16，轻标识使用用户指定的账号；原作者预设为 `@张馒头`，其他使用者未指定时不叠加账号标识，**不配背景音乐**。背景低存在感、不抢表达；工作桌面仅是本次样片的选择，不是后续视频的默认场景。

## 按当前阶段接续

### 1. 观点 → 口播稿

- 接收用户口述或文字观点，先理清她要表达的判断、理由、对象和希望观众记住的话。能从上下文判断的直接整理；仅在关键矛盾无法核实时询问。
- 保留她的语气和观点，不编造个人经历、客户案例、数据、效果或引用。以自然短句和清晰过渡整理，不把稿件写成营销口号。
- 结尾收住原观点，不扩出新主张。时长没有要求时，按观点完整度决定长度，并把稿件时长标为估计，不强压到30秒。
- 交付可修改的完整口播稿，让她确认或调整后本人录音。已经确认的正文不自行改写；用户已经按稿录音，视为该口播版本已经进入制作阶段，不重复索要同一稿件确认。
- 不生成替代声音。尚无录音时交付稿件并说明“待本人录音”，暂停依赖音频的步骤。

### 2. 本人录音 → 真实时间轴

- 读取用户指定的音频；引用聊天内附件时通过可用的聊天读取工具取得真实文件，不能只依据缓存中的文字稿。确认文件名、时长、可用音轨。
- 获取逐词/短语转写与时间戳，保留真实停顿；用波形或实际播放校准主要边界。优先复用未变化音频的转写缓存，缓存应关联源文件哈希。工具选择见 [执行与交付](references/production.md)。
- **以实际录音为准，不按文字稿机械均分。** 实录与确认稿有差异时说明，不补回未念出的句子。口误或不确定识别单独标出；没有确认的内容不要伪装成已听清。
- 区分音量、语速、停顿等可测线索与语义上建议强调的词。无法独立听辨的重音标为待人工确认，不把黄色词都宣称为真实最重音。
- “断点”默认指画面/字幕切换点，不等于删减录音。保留完整声音及自然呼吸；需删口误、重录或改变口播含义时先说明并取得对应授权。
- 根据每句话的信息密度设计单屏、分屏、原位换字或词语累积。长句优先视觉拆分，过短的小卡不要单独闪过；结尾关键词可累积并利用录音尾部静音定格。

### 3. 时间轴 → 画面与动效

- 读取 [已确认视觉模式](references/style.md)。按实录决定每段起止时间、屏幕文字、重点词、字号层级、位置、动画、颜色和停顿节奏；必要时标出视觉拆分原因。
- 屏幕文字可压缩连接词、分行和增加书面标点，但不能改变观点；核心结论尽量沿用实际口播。任何额外图解文字必须能由该段观点直接推出。
- 动效服务于节奏：短距离飞入/飞出、重点词轻放大、两组三连问原位换字、结尾逐词累积。允许用户要求更丰富，但不要默认每屏闪烁、旋转或大幅弹跳。
- **根据这条口播的内容、情绪和语义段落匹配背景，先判断“这段画面为什么适合这段表达”，不能默认每条都配工作近景。** 背景提供低存在感的氛围，观点文字承担主体；选择相互协调的场景与光线，景别和镜头数量由内容决定，一段连续素材也可以。做竖向构图、压暗、低饱和、轻模糊等必要处理，保留动作但不抢字。
- 背景优先复用可用且许可适合本次用途的用户素材或公开素材。公开素材明确标为氛围背景，不冒充用户真实经历；保存作者、来源、许可和处理记录。新素材获取失败时说明缺口，不用静态图推拉冒充已取得的视频背景。
- **不默认套用张馒头机器人、MG定版素材包、白底图标卡片或逐句配图。** 确有关系需要解释时，用少量文字、线条或箭头。用户明确要配图时才拓展；画面必须匹配表达，不能为了调用素材库硬用。

### 4. 制作 → 可播放视频

- 收到录音且制作范围清楚后，持续完成时间轴、背景匹配、排版、合成与检查，不为每个字号、镜头或例行动效反复申请批准。若用户只要求方案或先看时间轴，遵守该阶段边界。
- 默认输出带完整原声的9:16 MP4；音频与字幕同步。预览建议720×1280、30fps；需正式高清时输出1080×1920或用户指定规格。录音决定总长，不套用某次样片的45.66秒。
- 背景素材原声默认静音，**音乐默认关闭**。以后用户明确要求配乐，才另选符合其商用及署名要求的曲目，保存许可；不自动沿用任何历史曲目。
- 修改只针对本次用户反馈，保留已认可版本与无音乐版本，不顺带修改原素材库或其他技能。发布仍由用户手动完成，制作授权不等于上传或发布授权。

## 验收与交付

- 检查音频确实可读、转写覆盖整段；时间轴覆盖完整且无意外空隙、重叠或机械均分。
- 检查真实导出视频的时长、比例、帧率、音轨；抽查开头、结尾、长句、关键切点和代表性中段。确认文字未裁切、遮挡或过快，背景没有突然抢眼，声音无意外变速、删段或削波。
- 交付可直接播放的MP4、可编辑时间轴（CSV或JSON）以及必要的素材来源。编辑工程或字幕源按实际制作方式保留，不用一张静帧/网页预览代替视频交付。
- 在Codex中提供真实文件链接，能打开视频预览时直接打开。说明完成的检查；主观动效、重音听感、手机显示等未独立验证项标为“待人工确认”。没有实际生成并检查本地文件，不能宣称视频完成。

## 典型接续

- “我想表达一个观点……” → 从观点整理开始。
- “这是我录好的口播” → 读取指定录音，按实录直接进入时间轴和视频制作。
- “用观点口播视频skill做这条” → 沿用本模式，默认无音乐，不自动接入选题研究或发布流程。
- “这一段太干／动效太多／背景抢字” → 仅调整对应画面、动效或背景，已确认声音和正文保持。
