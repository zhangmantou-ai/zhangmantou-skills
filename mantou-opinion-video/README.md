# 张馒头观点口播视频 Skill

把真实观点变成本人原声、动态大字和低存在感视频背景组成的竖版视频。由张馒头的制作实践整理，朋友可以使用自己的观点、录音和账号。

**固定流程：观点 → 整理口播稿 → 本人录音 → 按实际语速拆时间轴 → 按内容匹配背景与字幕动效 → 导出并检查视频。**

## 这是什么

这是给支持 Skill 的 AI 助手使用的制作规范，不是独立剪辑软件，也不是自带模型和素材的一键生成器。包内不附私人录音、成片、第三方视频或字体。最终能否生成视频，取决于助手所在环境的转写、文件访问和视频合成能力。

默认9:16、暖白大字、黄色关键词、大量留白、少量有节奏的飞入/飞出和放大。背景根据每条口播的主题、情绪、语义匹配，不固定工作桌面，不硬套MG图库。本人原声，默认无背景音乐。

## 安装到 Codex

1. 在 [GitHub 仓库](https://github.com/zhangmantou-ai/zhangmantou-skills) 选择 Code → Download ZIP 并解压，也可以下载单独的 Skill 开源包。
2. 找到 `mantou-opinion-video` 整个文件夹。
3. 复制到 Codex 技能目录。默认路径如下；如设置了 `CODEX_HOME`，则使用该目录下的 `skills`：
   - macOS / Linux：`~/.codex/mantou-opinion-video/`
   - Windows：`%USERPROFILE%\.codex\skills\mantou-opinion-video\`
4. 确认该目录里直接存在 `SKILL.md`，不要多套一层文件夹。在下一轮对话中调用 `$mantou-opinion-video`；若未识别，重新打开 Codex。

已有同名版本时，先备份再替换该文件夹，不覆盖其他技能。

也可让 Codex 安装：

> 请用 skill-installer 安装 https://github.com/zhangmantou-ai/zhangmantou-skills/tree/main/mantou-opinion-video

## 怎么使用

第一步，表达观点：

> 使用 $mantou-opinion-video。我想表达的观点是：很多人做产品时先想自己想卖什么，最后才找客户。我希望讲清楚为什么应该先理解谁愿意为什么付钱。请先帮我整理口播稿。我的账号标识是 @我的名字。

第二步，确认稿件并自己录音。支持的音频格式由当前工具决定，常用 MP3、WAV 或 M4A。声音尽量清楚，保留自然停顿。

第三步，上传录音继续：

> 这是我录好的口播。请按实际录音设计字幕时间轴和动效，根据内容匹配低存在感的视频背景，制作9:16视频。保留完整原声，不加背景音乐。

也可以直接从已有稿件或录音开始。其他使用者不会自动带上`@张馒头`；未指定账号时省略标识。

预期交付：可播放 MP4、可编辑 CSV/JSON 时间轴、素材来源与许可记录。时间轴包括起止时间、屏幕文字、重点词、字号、位置、动效、颜色、停顿和背景。主观听感和手机显示由使用者最终确认。

## 运行环境与成本

- 需要能读取上传录音并转写、校准时间戳的工具。本地 Whisper 是一种选择，不强制某个服务。
- 需要视频合成工具，例如 FFmpeg 搭配 Pillow，或其他可用编辑工具，以及合法可用的中文字体。工具选择由助手根据环境决定。
- 需要用户自有背景素材，或可获取且许可符合用途的素材。公开素材需记录来源、作者、许可与使用日期。
- 本 Skill 不附安装脚本、不强制 API key 或付费服务；免费流程是否可行取决于已有设备和工具。使用外部模型或服务可能产生费用，媒体上传按当前授权处理。
- 环境缺少转写或合成能力时，助手应说明缺项并交付已完成的稿件/时间轴，不把方案称为已生成的视频。

## 文件位置

- `mantou-opinion-video/SKILL.md`：工作流程。
- `mantou-opinion-video/references/style.md`：视觉、动效参数。
- `mantou-opinion-video/references/production.md`：转写、合成和交付规范。
- `mantou-opinion-video/references/preferences.md`：个人设置与账号替换。
- `examples/first-use.md`：可直接复制的首次使用提示。

生成文件保存位置由当前工作区决定，请让助手给出视频的真实文件链接。Skill 本身不固定输出到原作者电脑，也不自动发布视频。
