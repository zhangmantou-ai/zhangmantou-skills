# Mantou XHS Object Cover

一个面向 Codex 的小红书封面 Skill：用**真实设备或产品照片**做证据和视觉锚点，产出标题清楚、可直接发布的 3:4 封面。适合 ESP32、M5Stack、旧设备改造、桌面工具与实物工作流。

它不是通用的 AI 海报生成器：真实物件应当保留身份、屏幕、接口和使用语境，封面再用贴纸标题、功能标签和少量涂鸦帮助读者一眼看懂。

## 安装与调用

将整个 `mantou-xhsobj-cover/` 文件夹复制到 Codex Skill 目录（通常是 `~/.codex/skills/`），刷新或重启 Codex 后调用：

```text
$mantou-xhsobj-cover
```

示例提示词：

```text
使用 $mantou-xhsobj-cover，把这张 M5Stack 实拍图做成小红书封面。
标题必须是“你们都用 ESP32 做了什么？”。
已确认功能：Hermes、语音交互、余额显示。
参考图只参考黄字黑描边和手帐贴纸风格。
```

## 何时使用

- ESP32、M5Stack、Arduino 等 DIY 硬件项目
- 翻页笔、键盘、桌面配件等旧物改造
- 有实物证据的工具介绍、工作流或产品改造帖
- 需要真实照片＋醒目手写贴纸标题的小红书封面

不适合人像情绪帖，或以软件结果截图为唯一证据的内容；这两类内容应改用人物主角或截图主角的封面策略。

## 先选对主角

| 内容的真正看点 | 采用的主角 | 画面原则 |
|---|---|---|
| 改造后的设备本身 | 物件主角（默认） | 物件占下半区 45–60%，白描边强调轮廓 |
| 创作者的反应、体验或故事 | 人物主角 | 人物占主位，物件只提供语境 |
| 软件结果、前后对比、数据 | 截图主角 | 截图负责证明，设备是次级线索 |
| 按、握、说等实际操作 | 物件＋手 | 只在手能说明尺寸或交互时使用 |

## 核心规则

1. **照片真实。** 用户提供的物件图是编辑目标，不用虚构产品渲染替代。
2. **标题第一。** 默认输出 1080×1440、3:4 成品；主标题占上方 30–35%，缩略图也应优先可读。
3. **信息克制。** 只保留一个分类标签、一个功能贴纸和少量引导性涂鸦，不把封面写成说明书。
4. **功能可核。** 标题、品牌、工具名和功能标签按用户已确认的内容写；不虚构性能、延迟、兼容性、数据、价格、Logo 或 UI。
5. **成品必检。** 检查物件辨识度、文字拼写、功能真实性、主物件无遮挡、尺寸和缩略图可读性。

完整的布局与验收细则见 [layout-and-qa.md](layout-and-qa.md)。

## 视觉语言（可按照片调整）

默认适配真实桌面图的轻手帐科技风：黄字黑描边、白色贴纸轮廓、蓝色分类标签、薄荷绿或青色点缀、少量箭头与星点。亮底照片上不要直接压黄字；应先加入深色标题区，或改用黑底黄字的小标签，确保对比度。
