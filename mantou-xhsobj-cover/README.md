# Mantou XHS Object Cover

这不是只有 Codex 才能用的 Skill，而是一套可迁移的**实体物件小红书封面工作流**：用真实照片中的物件做证据和视觉锚点，产出标题清楚、可直接发布的 3:4 封面。

它适合产品、小物、手作、桌面物件、工具、改造项目，以及随手拍的食物或饮品；核心不是“科技硬件”，而是**物件本身是画面的主角，不是人物肖像**。真实物件应保留其材质、形态和使用语境，再用标题、标签和少量涂鸦帮助读者一眼看懂。

## 怎么用：Codex 与其他 AI 工具

### 在 Codex 中原生调用

将整个 `mantou-xhsobj-cover/` 文件夹复制到 Codex Skill 目录（通常是 `~/.codex/skills/`），刷新或重启 Codex 后输入：

```text
$mantou-xhsobj-cover
```

### 在 Claude、ChatGPT、WorkBuddy 等工具中使用

它们不一定识别 `$mantou-xhsobj-cover` 这条命令，但规则同样可用：把 [SKILL.md](SKILL.md) 复制到项目指令、自定义工作流或对话首条消息，再附上照片、标题（如已有）和已确认信息。

通用调用模板：

```text
请按下面的实体物件小红书封面规则工作：
【粘贴 SKILL.md 内容】

素材：我提供的真实照片
主标题：______（已有就填；没有就留空）
标题模式：指定标题 / 先出 3 个候选 / 你直接主推一个
已确认的信息或功能：______
风格参考：______（可选）
请输出 1080×1440、3:4 的完整封面；不要虚构照片中没有的物件、功能或数据。
```

### 标题有两种使用方式

1. **客户已有标题：** 原样作为主标题使用；工具只建议断行或更短的封面版，不擅自改写。
2. **客户没有标题：** 默认先根据照片、主题和已确认信息生成 3 个标题候选，客户选定后再做成品封面。

只有客户明确说「你直接决定」时，工具才会自动选出主推标题，并先说明标题与依据。图片本身不足以证明功能或效果时，会先索取一句背景，避免写出不实卖点。

Codex 调用示例：

```text
使用 $mantou-xhsobj-cover，把这张咖啡和甜点的随手拍做成小红书封面。
主标题是“周末的快乐，先从这一口开始”。
参考图只参考黄字黑描边和手帐贴纸风格，不要添加人物或虚构菜品。
```

无标题调用示例：

```text
使用 $mantou-xhsobj-cover，用这张随手拍的咖啡和甜点做小红书封面。
我还没有标题：先给我 3 个标题候选，我选定后你再出封面。
已确认信息是「周末探店、现烤可颂」；不要虚构口味、评分或人气。
```

## 何时使用

- 产品、小物、文具、香薰、器皿、玩具或手作成品
- 咖啡、甜点、便当、饮品等随手拍美食
- 花、植物、桌面角落、家居小物等生活方式实拍
- 翻页笔、键盘、设备、工具与 DIY 改造项目

不适合人物肖像、人物反应或情绪表达主导的封面；也不适合以软件结果截图为唯一证据的内容。前者改用人物主角，后者改用截图主角。

## 先选对主角

| 内容的真正看点 | 采用的主角 | 画面原则 |
|---|---|---|
| 产品、食物、手作或设备本身 | 物件主角（默认） | 物件占下半区 45–60%，白描边强调轮廓 |
| 创作者的反应、体验或故事 | 人物主角 | 人物占主位，物件只提供语境 |
| 软件结果、前后对比、数据 | 截图主角 | 截图负责证明，设备是次级线索 |
| 按、握、说等实际操作 | 物件＋手 | 只在手能说明尺寸或交互时使用 |

## 核心规则

1. **照片真实。** 用户提供的物件图是编辑目标，不用虚构产品、食物或设备替代。
2. **标题第一。** 默认输出 1080×1440、3:4 成品；主标题占上方 30–35%，缩略图也应优先可读。
3. **信息克制。** 只保留一个分类标签、一个功能贴纸和少量引导性涂鸦，不把封面写成说明书。
4. **标题可控、功能可核。** 有标题时忠实保留；无标题时先给 3 个候选再确认。标题、品牌、工具名和功能标签只按用户已确认的内容写；不虚构性能、延迟、兼容性、数据、价格、Logo 或 UI。
5. **成品必检。** 检查物件辨识度、文字拼写、功能真实性、主物件无遮挡、尺寸和缩略图可读性。

完整的布局与验收细则见 [layout-and-qa.md](layout-and-qa.md)。

## 视觉语言（可按照片调整）

默认适配真实照片的轻手帐贴纸风：黄字黑描边、白色贴纸轮廓、蓝色分类标签、少量箭头与星点。可随素材换成暖奶油、食物橙红、植物绿或科技薄荷绿。亮底照片上不要直接压黄字；应先加入深色标题区，或改用黑底黄字的小标签，确保对比度。
